GitHub Pages Kurulum ve Video Yapılandırma Rehberi

1. GitHub Deposu Yapısı

Sitenizin ve video dosyanızın sorunsuz yüklenmesi için GitHub deposundaki klasör hiyerarşisi tam olarak şu şekilde olmalıdır: 

my-airpods-site/
├── index.html        (Bu dosya)
└── assets/
    └── video.mp4     (Detay videonuz)

* Not: HTML dosyasındaki video etiketi path olarak ./assets/video.mp4 yolunu kullanır.

2. Videonun Son Karede Donma Mantığı

Videonun bittiğinde başa dönmemesi veya siyah kalmaması için HTML5 JavaScript API'sinde ended olayı (event) dinlenir: 

video.addEventListener('ended', () => {
    // Video bittiğinde duraklatır ve 
    // son karede takılı kalmasını sağlar
    video.pause();
    console.log("Video son karede donduruldu.");
});
